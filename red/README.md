# Recursos Educativos Digitais (RED)

Recursos destinados ao ensino e à aprendizagem de Inglês do 8.º ano e Português do 11.º ano.

Criar uma subpasta por recurso, à medida que seja desenvolvido. Acompanhar cada recurso de uma breve descrição com destinatários, objetivos, instruções de utilização, requisitos técnicos, autoria e fontes.

Registar versões, alterações, verificações de funcionamento e aspetos de acessibilidade. Incluir apenas ficheiros e elementos gráficos cuja divulgação seja permitida.
